About this website

Content

All content on this website, including the texts, research descriptions, publication lists, teaching information and photograph, was written or provided by me, and I am responsible for it. Papers are linked to arXiv and to the journals’ own pages; the rights to published articles remain with the respective publishers.

Design and code

The layout and code of this website were created with the help of an AI assistant (Claude, by Anthropic), under my direction. The site consists of plain HTML and CSS pages and is hosted on GitHub Pages.

The pattern in the page header is a random tessellation, sampled afresh in your browser on every visit. It cycles through five models: the Poisson–Voronoi tessellation, the Boolean model, and the β‑Voronoi, β′‑Voronoi and Gaussian–Voronoi tessellations.

Visitor statistics

To see how many people visit this website and which pages they read, I use Umami Cloud, a privacy-friendly analytics service. It sets no cookies and stores no personal data. Your IP address is used only to estimate an approximate location (country, region and city) and is not stored, and visitors cannot be recognised across different websites or beyond one month. The statistics are kept for six months.

You can switch off the visitor statistics for this browser.

Third-party services

The pages are served by GitHub Pages (GitHub, Inc.), which processes visitors’ IP addresses in its server logs; see the GitHub Privacy Statement. Fonts are loaded from Google Fonts and icons from jsDelivr; to display them, your browser connects to these services.
